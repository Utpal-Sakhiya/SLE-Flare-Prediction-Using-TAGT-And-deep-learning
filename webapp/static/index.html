What is an SLE flare?

Systemic lupus erythematosus (SLE, or lupus) is a long-term autoimmune disease: the immune system attacks the body's own tissues, such as skin, joints, kidneys and blood cells. It usually alternates between quieter periods and flares, when symptoms and inflammation get worse.

Doctors track disease activity with the SLEDAI-2K score, a checklist of clinical and laboratory findings (0 means inactive; higher means more active). Knowing that a flare is likely could prompt an earlier check-up or a change in treatment.

What this system does

For one clinic visit it takes – gene-expression values from a blood sample, the current SLEDAI-2K score and whether the patient is flaring now. It returns a flare risk score for the next visit.

A clinical-only logistic regression runs alongside as a baseline. The Results page compares every model on patients it never saw during training.

How the model works

TAGT (Temporal Attention Graph Transformer) in three steps.

  1. Input: – probe values 1

    Gene encoder

    Each probe is standardised, then heavy input dropout (70% during training) and a two-layer network compress the profile into 128 numbers.

  2.   2

    Projection + attention

    A projection layer and 8-head self-attention re-weight that 128-number gene summary.

  3. Input: SLEDAI-2K + flaring now 3

    Clinical fusion

    The two clinical inputs are encoded and joined with the gene summary. A small classifier outputs the flare risk score.

    Methodology

    How the data was built, how TAGT was trained and evaluated, and what this evaluation can and cannot show.

    Dataset provenance

    Semi-synthetic. The gene-expression profiles are real whole-blood microarray data from GEO series GSE49454 (Illumina). The patients, their visit sequences, SLEDAI-2K scores and flare labels were simulated by src/data/process_real_data.py, and each simulated visit was given a randomly chosen real profile plus noise.

    • Simulated patients–
    • Gene probes–

    Because expression was assigned to visits at random, it carries little genuine link to the outcome. Gene-based models can only find weak or spurious signal here.

    Inputs and target

    • Gene expression: – log2 probe values, standardised per probe with the training fold's mean and SD.
    • SLEDAI-2K at the current visit (divided by 20).
    • Flaring now (0 or 1).
    • Target: whether the patient flares at the next visit.

    Model

    • Gene encoder: input dropout 0.7 → 1,000→256 → ReLU → dropout 0.3 → 256→128.
    • Projection + attention: 128→128 projection with ReLU, then 8-head self-attention (128-d).
    • Clinical encoder: 2→32 with ReLU.
    • Classifier: 160→128→64→1 with dropout 0.3; a sigmoid gives the risk score.

    In this compact deployed variant, the "graph" step is a dense projection (no gene–gene interaction network is applied), and attention runs over a single visit, so it does not model multi-visit sequences.

    Training

    • Optimiser AdamW, learning rate 1e-3, weight decay 0.05.
    • 15 epochs, batch size 32, gradient clipping at 1.0.
    • Input dropout 0.7 on the gene branch, plus Gaussian noise (σ = 0.1) on standardised expression.
    • Class-balanced binary cross-entropy (positive weight = non-flares ÷ flares).

    Cross-validation plus the final fit took – on CPU (trained –).

    Validation

    –. All visits from one patient stay in the same fold, so every score is measured on patients the model never saw.

    • AUC-ROC is computed on the pooled out-of-fold predictions; fold AUCs are reported as mean ± SD.
    • Decision thresholds maximise Youden's J on those same out-of-fold scores, so accuracy, sensitivity and specificity are slightly optimistic.
    • The deployed models are then refit on all visits, so predictions for dataset visits on the Predict page are in-sample.

    Baselines

    • Logistic regression (clinical): SLEDAI-2K and flaring now only, standardised.
    • Logistic regression (genes + clinical): all 1,002 inputs, strong L2 penalty (C = 0.01).
    • Random forest (genes + clinical): 300 trees, minimum 3 samples per leaf.

    Gene attributions on the Predict page are gradient × input on the standardised expression for the deployed TAGT model, top 10 by absolute value.

    Limitations

    • Semi-synthetic data. Clinical trajectories and labels are simulated, so no result here is evidence of clinical performance.
    • Small cohort. – patients, so each test fold holds only about – of them, and fold AUCs vary widely.
    • Scores are not calibrated probabilities. Read them as a ranking of risk, not as "the chance of a flare".
    • No external validation. The models have not been tested on an independent cohort.
    • The earlier 0.943 AUC claim does not hold. Documents elsewhere in this repository report AUC 0.943. That pipeline fed the model the change in SLEDAI-2K from the current to the next visit (next_sledai − current_sledai), which is information from the future visit, and it did not keep each patient's visits in one fold. Without that leak, under patient-grouped cross-validation, the figure does not reproduce. The numbers on the Results page replace it.
